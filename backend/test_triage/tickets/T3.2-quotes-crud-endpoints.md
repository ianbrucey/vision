# T3.2 — Quotes CRUD Endpoints

**Status:** pending
**Depends on:** T3.1

---

## Goal

Full CRUD for quotes. Permissioned: quote owner can edit their own quotes, admin can edit all.

## Routes

```
POST   /api/solicitations/{id}/quotes          — create a quote
GET    /api/solicitations/{id}/quotes           — list quotes
PATCH  /api/solicitations/{id}/quotes/{qid}     — update quote
DELETE /api/solicitations/{id}/quotes/{qid}     — delete quote
```

### POST /api/solicitations//quotes

```json
// Request
{
  "notes": "Spoke with ABC Corp. They can do the masonry work but need to see the parapet wall first.",
  "amount": 45000.00,           // optional
  "poc_name": "Jane Smith",     // optional
  "poc_email": "jane@abccorp.com",
  "poc_phone": "541-555-0123"
}

// Response 201
{
  "id": 1,
  "external_id": "uuid",
  "solicitation_id": 5816,
  "created_by": "uuid",
  "notes": "...",
  "amount": 45000.00,
  "poc_name": "Jane Smith",
  "poc_email": "jane@abccorp.com",
  "poc_phone": "541-555-0123",
  "status": "draft",
  "created_at": "...",
  "updated_at": "..."
}
```

### PATCH /api/solicitations//quotes/

Any field can be updated. Status transitions are validated:

- `draft` → `pending_site_visit` or `submitted` or `lost`
- `pending_site_visit` → `submitted` or `lost`
- `submitted` → `awarded` or `lost`
- `awarded` and `lost` are terminal (no further transitions)

### DELETE

Only draft quotes can be deleted. Submitted/awarded/lost quotes are kept for audit trail.
