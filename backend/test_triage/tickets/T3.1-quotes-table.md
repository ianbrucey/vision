# T3.1 — Quotes Table

**Status:** pending
**Depends on:** nothing

---

## Goal

Create a `quotes` table to store subcontractor quotes attached to solicitations. Each quote has a status, freeform notes, POC info, and optional dollar amount.

## Migration

```sql
CREATE TABLE quotes (
    id              serial PRIMARY KEY,
    external_id     uuid DEFAULT gen_random_uuid(),
    solicitation_id integer NOT NULL REFERENCES solicitations(id) ON DELETE CASCADE,
    created_by      uuid NOT NULL REFERENCES users(id),

    -- Quote details
    notes           text,              -- freeform text area
    amount          numeric(12,2),     -- optional dollar amount
    poc_name        text,              -- point of contact at subcontractor
    poc_email       text,
    poc_phone       text,

    -- Status
    status          text NOT NULL DEFAULT 'draft'
                    CHECK (status IN (
                        'draft',
                        'pending_site_visit',
                        'submitted',
                        'awarded',
                        'lost'
                    )),

    -- Optional attachment (e.g. formal quote PDF)
    document_id     integer REFERENCES documents(id),

    created_at      timestamptz DEFAULT now(),
    updated_at      timestamptz DEFAULT now()
);

CREATE INDEX idx_quotes_solicitation ON quotes(solicitation_id);
CREATE INDEX idx_quotes_created_by ON quotes(created_by);
```

### Status lifecycle

```
draft ──→ pending_site_visit ──→ submitted ──→ awarded
  │                                              │
  └──────────────────────────────────────────────→ lost
```

| Status | Meaning | When to use |
|---|---|---|
| `draft` | Being worked on | Initial creation |
| `pending_site_visit` | Waiting on site visit | Sub needs to see the site before quoting |
| `submitted` | Quote received | Sub sent formal quote, under review |
| `awarded` | Won the work | This sub got the contract |
| `lost` | Didn't win | Quote was rejected or sub declined |
