# T2.1 — Solicitation Assignee Column

**Status:** pending
**Depends on:** nothing

---

## Goal

Add `assignee_id` and `assigned_at` columns to the `solicitations` table so a solicitation can be claimed by a user.

## Migration

```sql
ALTER TABLE solicitations
  ADD COLUMN assignee_id uuid REFERENCES users(id),
  ADD COLUMN assigned_at timestamptz;
```

- `assignee_id` — FK to `users.id`, NULL = unassigned
- `assigned_at` — timestamp of when it was claimed (set on claim, cleared on release)
