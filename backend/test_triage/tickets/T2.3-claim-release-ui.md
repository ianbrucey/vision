# T2.3 — Claim / Release UI

**Status:** pending
**Depends on:** T2.2

---

## Goal

Users see assignment status on the solicitations list and case detail. They can claim and release solicitations from the UI.

## Solicitations Page Changes

Add an "Assignee" column to the table:

```
┌──────────────────────────────────────────────────────────────────┐
│ Title                    Type      Agency     Assignee    Status │
│──────────────────────────────────────────────────────────────────│
│ IMT RiverWare Support    Solicit.. DOI       ─── [Claim]  active │
│ PDT Wall Repair          Solicit.. NOAA      ianbruce ✓  active │
│ AFHC Repair Quarters     Solicit.. USACE     admin   ✓   active │
└──────────────────────────────────────────────────────────────────┘
```

- Unassigned rows: show "—" and a **Claim** button
- Assigned to current user: show username with checkmark, **Release** button
- Assigned to other user: show their username (no action available)
- Admin: sees dropdown to reassign

## Case Detail Header

Add assignee info to the case header:

```
PDT EXTERIOR WALL REPAIR AT PENDLETON WFO
Solicitation #1305M326Q0429 | NAICS 238140 | Assigned to: ianbruce [Release]
```

## Files to Touch

| File | What |

## Acceptance Criteria

- [ ] Solicitations list shows assignee for each row
- [ ] "Claim" button on unassigned rows → clicking claims it, row updates
- [ ] "Release" button on rows assigned to current user → clicking releases, row updates
- [ ] Rows assigned to other users show their username, no action buttons
- [ ] Admin sees a dropdown to reassign to any user
- [ ] Case detail header shows assignee with claim/release controls
- [ ] Optimistic UI: button changes immediately, reverts on error
