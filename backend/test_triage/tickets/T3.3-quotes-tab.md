## Status Progression Buttons

Contextual buttons based on current status:

| Current Status | Available Actions |
|---|---|
| `draft` | Mark Pending Site Visit, Submit, Edit, Delete |
| `pending_site_visit` | Submit Quote, Edit |
| `submitted` | Mark Awarded, Mark Lost |
| `awarded` | (none — terminal) |
| `lost` | (none — terminal) |

## TabNav Note

Only show the Quotes tab on solicitation-backed cases. The tab should appear after Triage and before Vendor Matches in the tab order.

## Acceptance Criteria

- [ ] "Quotes" tab visible on solicitation-backed cases
- [ ] "Add Quote" opens form with: notes textarea, amount, POC name/email/phone
- [ ] Saving creates quote, appears in list immediately
- [ ] Each quote card shows: status badge, POC name, amount, age
- [ ] Status badge color-coded: draft=gray, pending_site_visit=yellow, submitted=blue, awarded=green, lost=red
- [ ] "Mark Pending Site Visit" button → status changes, card updates
- [ ] "Submit" button → status changes to submitted
- [ ] Edit button → inline edit mode for notes, amount, POC
- [ ] Delete button → confirmation dialog → removes card
- [ ] Non-owner non-admin cannot see edit/delete buttons
