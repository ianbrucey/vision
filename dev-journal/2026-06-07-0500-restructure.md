### Upload flow (new)

```
User uploads file via frontend
  → POST /api/cases/{id}/ingest (multipart)
    → saved to MinIO immediately (< 1s)
    → job record created (status: queued)
    → returns { job_id, status, storage_ref }
  → frontend polls GET /api/jobs/{id}
  → background worker claims job (SKIP LOCKED)
    → downloads from MinIO
    → processes (OCR/transcription/extraction)
    → indexes into evidence store (documents → sections → blocks)
    → marks complete
  → frontend shows "complete" with progress bar
```
