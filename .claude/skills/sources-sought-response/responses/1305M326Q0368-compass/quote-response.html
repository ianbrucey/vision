2. C++ Programming Experience

Mr. Rochelle brings approximately 20 years of professional software engineering experience (2006–present), including 12+ years as Enterprise Computer Software Architect / VP at J2 Innovations — the company behind the FIN Framework, a Qt/QML-based C++ software framework for building automation and IoT — and subsequent service as Enterprise Software Architect at Siemens, which acquired J2 Innovations in 2019. This experience maps directly to COMPASS's technical profile: object-oriented design across many .cpp files, a Qt-based graphical interface, cross-platform compilation (Windows primary; Linux and macOS), Boost in the toolchain, and Git-based development with documented build processes. His physics degree supports the quantitative and calibration-oriented nature of model development work.

3. Custom Software Work and Model Support

Justice Quest LLC contributes a 10+ year commercial software delivery record, including performance-critical production systems: direction of a full platform migration sustaining 99.9% production uptime over three years; rapid root-cause resolution of critical defects in a high-volume production engine under revenue-critical conditions; and established CI/CD, documentation, and zero-downtime migration practice. These capabilities support the non-scientific dimensions of this contract: routine maintenance, code efficiency and memory management discipline, regression-safe modification of large codebases, Windows installer packaging, and disciplined reporting.

4. Ecological and Wildlife Behavioral Modeling — Proposed Approach

Justice Quest LLC and Mr. Rochelle have no prior past performance in salmon or fisheries ecological modeling specifically. Our approach is therefore collaboration-first:

  • Embed with NOAA science staff. Implement ecological components concurrently developed by project scientists; calibrate parameters to radio-telemetry and PIT-tag data in collaboration with the project team, as the Statement of Work directs.
  • Deliverable-based progress. Each SOW task (GUI completion, adult passage module, West Coast Region products, routine maintenance) is a separate billable deliverable with written documentation demonstrating that the update works as expected — matched to the SOW's parity-based acceptance tests.
  • Priority-ordered execution. We will follow the SOW's task priority order and adjust the proportion of time across tasks monthly in coordination with the NOAA project leader, with weekly-to-monthly progress reports and documentation updates as specified.

  • Code efficiency: The current runtime profile (5–30 second scenario-years; Monte Carlo runs of tens of thousands of scenario-years at 24–48 hours; ~200 MB memory footprint) will be treated as the regression baseline; all new code will be validated against parity acceptance tests before delivery.
